# 恢复状态模型原型（一次性，用完即弃）

问题：spec #1 与 ADR 0001–0004 定下的恢复状态模型，能否在所有实验组和故障条件下保证不重复写入、不基于失效条件写入？哪里有歧义或缺陷？

全部在内存中模拟：执行库、业务服务、网络、时钟、执行实例与故障注入。不连数据库，不调用模型，不走 HTTP。

运行（Node 26）：

- `node run.ts`：完整矩阵（实验组 × 故障条件 × 两种幂等模式）及效率对照
- `node run.ts fixes`：加入两项修正后重跑相关条件
- `node run.ts <实验组> <条件> <idem|nonidem>`：打印单次运行的完整轨迹

实验组：`A`、`B`、`C`、`B-verify`、`B-recheck`、`B-recheckFirst`（先复查后核验，用来验证顺序约束）。
