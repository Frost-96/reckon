要回答的问题：售后 Agent 的执行内核在任务执行中途出故障后，按"按步骤日志重建 → 核验结果未知的写入 → 复查易变读 → 由业务规则给出处置"的顺序恢复，配合租约版本校验和写请求处理时限 Δ，能否在各实验组和各类故障下做到不重复写入、不按失效条件写入？原型发现的修正项（P1 售后规则易变与运费校验、P2 按 client_ref 识别本任务写入、P3 补全写入意图状态转换）是否真的改变结果？
