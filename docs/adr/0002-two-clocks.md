# 租约用真实时间，业务时间用可缩放的逻辑时钟

租约与心跳一律用 PostgreSQL 的 `now()`，即不缩放的真实时间。写请求处理时限 Δ、503 时间窗、退避调度和最长等待时间，则用 `T0 + (实际时间 − R0) × k` 计算的逻辑时钟。只有一种时钟时，为了把小时级的外部不可用压缩到分钟级，租约也会被同比例压缩：k = 60 时，10 秒的租约只剩约 170ms，一次 GC 停顿就会被误判为租约丢失。Δ 只在执行进程和业务服务之间比较，两边都用逻辑时钟，口径一致；所有容器共用宿主机内核时钟，所以"共用时钟源"这一假设在物理上成立。k 默认为 1，只有"长时间不可用"条件使用更大的值。
