# 界面原型（一次性，用完即弃）

问题：对话工作台和单任务执行时间线最终应该长什么样？

三个布局变体在同一个页面上，用 `?variant=A|B|C` 或底部的切换条（也可以按 ← →）切换。全部是写死的假数据，状态只在内存里。

打开：双击 `workbench-timeline.PROTOTYPE.html`。

- `A` 分栏工作台：左边对话，右边时间线、写入意图和业务库
- `B` 时间线泳道：顾客、实例 1、实例 2、业务服务、执行库五条泳道，对话收在右侧抽屉
- `C` 答辩舞台：顾客看到的、系统内部、业务库的真相三栏，加阶段条和大字解说

其他参数：

- `?auto=kill|drop|zombie|competing|refunded|fee`：打开后自动演示对应的故障
- `?speed=1|2|4|8`：播放速度
- `?env=prod`：隐藏演示控制，看生产环境下的样子
